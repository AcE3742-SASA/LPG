# Citing LPG

Use the versioned [v1.0.0 release](https://github.com/AcE3742-SASA/LPG/releases/tag/v1.0.0) to identify the code and data accompanying the reported results. [CITATION.cff](../CITATION.cff) supplies the author order, version, and release date.

홍이준, 전유찬. (2026). *LPG: Latency Prediction Through GEMM Building Blocks* (Version 1.0.0) [Software and data]. GitHub. https://github.com/AcE3742-SASA/LPG/releases/tag/v1.0.0

```bibtex
@software{hong_jeon_lpg_2026,
  author = {홍, 이준 and 전, 유찬},
  title = {{LPG}: Latency Prediction Through {GEMM} Building Blocks},
  year = {2026},
  version = {1.0.0},
  date = {2026-11-13},
  publisher = {GitHub},
  url = {https://github.com/AcE3742-SASA/LPG/releases/tag/v1.0.0}
}
```
