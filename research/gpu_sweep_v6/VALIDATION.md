# v6 검증 기록

2026-09-19 macOS의 Python 표준 라이브러리 환경에서 검증했다. v6 GPU 파일럿과 full은 아직 실행하지 않았다.

## 변경 범위

기존 v5를 별도 `gpu_sweep_v6/`로 복사했다. 주 측정·경계 조건에 Graph를 추가하고 prealloc과 짝으로 저장한다. 파일럿은 바뀐 GEMM 경로만 192작업으로 검증한다. 기존 v5 소스 13개의 SHA-256과 입력 provenance가 유지됐음을 대조했다.

Graph GEMM 묶음은 별도 진단으로 확인한 작은 세 조건에서 64회로 고정한다. 나머지는 기존 2 ms 목표·최대 64회 선택을 사용하되 첫 선택을 저장해 같은 형상·dtype의 round·재시작·pilot→full에서 유지한다. 타이머·정확성 검사·180초 예열·3초 안정화·7블록·100 ms 목표·5% 변동 기준은 유지했다. v6 프로토콜 버전은 4다.

GNOME portal의 정확한 경로를 데스크톱 허용 목록에 추가했다. 종료 코드 2는 이번 실행의 완료된 REVIEW summary가 있을 때만 REVIEW로 표시한다. 종료한 로그를 자동으로 ZIP에 넣는다.

## CPU 검증

표준 라이브러리 unittest 33개를 통과했다. 기존 23개 검사와 v6 10개 검사를 포함한다.

- 주 측정·경계 조건의 빠짐없는 두 방식 배치, 인접 순서·round 교대·동일 입력 seed, pilot 192와 full 78,952작업 생성.
- Graph 묶음 선택·유효 범위·저장값 복원·충돌 차단, 고정 묶음의 재probe 방지와 캡처 횟수.
- 양쪽 시간을 분리한 CSV, 한쪽 누락 처리, 입력 seed 불일치 차단, fresh holdout 짝 결과 분리.
- 기존 코드·환경·프로토콜 검사와 함께 실제 v6 pilot 작업 목록 일치 검사.
- 가짜 CUDA로 실제 수집 함수를 실행해 두 번째 작업 뒤 중단·저장·재시작을 재현. 완료 작업을 건너뛰고 Graph의 최초 묶음 수를 다음 round에서 재사용하는지 확인.
- 래퍼의 실제 셸 판정 부분에서 완료된 REVIEW, 누락, FAIL, 오래된 summary, summary 없음을 비교. 원래 종료 코드 2를 보존하며 완료된 이번 REVIEW만 구분.
- GNOME portal의 정확한 경로 허용과 다른 경로 차단.
- 기존 manifest 불일치, 잠금, SQLite 실패 이력, 정확성·변동 판정, profiler 보고서 검사, 명령·경로·종료 코드 전달 회귀 검사.

Python AST와 Bash 구문 검사를 통과했다. 실제 192작업 계획의 합성 결과로 완료 summary·96쌍·full 진입의 파일럿 검증 함수를 추가 확인했다. 합성 시간은 소프트웨어 검사에만 사용하고 GPU 관측값으로 보관하지 않는다.

## 사전 계획

pilot은 24형상 × 2정밀도 × 2방식 × 2 round로 192작업·96쌍이다. 7블록씩 1,344개 블록을 수집한다. profiler·대조·연결 실험은 이 파일럿에 포함하지 않는다.

full은 주 측정 72,024, 대조 5,256, 경계 900, 연산 기준 18, 대역폭 9, 연결 702, 프로파일링 43으로 총 78,952작업이다. prealloc·Graph 쌍은 37,776개다. 주 측정 6,002형상의 split은 development 219, legacy train 3,348, validation 717, 이미 탐색한 legacy test 718, fresh holdout 1,000으로 기존과 같다.

## GPU에서 남은 검증

새로운 두 방식 수집 순서에서 실제 CUDA Event·Graph 실행, 수치 검사, 변동, 메모리 사용, 환경 검사와 자동 결과 ZIP을 확인해야 한다. 로컬의 가짜 CUDA·셸 검사로 실제 GPU 실행 성공을 주장하지 않는다.

앞서 업로드된 별도 Graph 묶음 진단의 48측정·336블록은 작은 세 조건에서 64회를 사용할 근거다. 다른 모든 형상의 묶음 수 수렴, CPU 영향 0, 순수 커널 시간이나 그래픽 간섭 부재를 입증하지 않는다. 기존 v5 REVIEW도 이번 코드 준비로 해소된 것이 아니다.

로컬 검증 로그·계획 집계·기준 소스 hash·배포 ZIP 대조는 자율연구 `analysis/gpu_sweep_v6_2026-09-19/`에 저장한다. 파일럿을 검토한 뒤 full 실행 여부와 예상 시간을 결정한다.
