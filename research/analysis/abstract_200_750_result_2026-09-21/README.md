# 750 MHz 200형상 부분수집 검토 — 2026-09-21

일시정지와 재개는 정상 작동했다. 이후 `(2329,3998,66)` FP32에서 순간 전력 제한·735 MHz 표본과 시간 변동이 확인되어 1,236/3,600측정에서 자동 중단됐다. **750 MHz의 200형상 안정성이 검증된 결과가 아니다.** 원자료는 보존하고 단순 재개는 보류한다.

## 수집 범위와 중단

- PASS 1,233 / REVIEW 3 / FAIL 0, 미수집 2,364건. 8,652개 시간 블록과 412개 세 방식 묶음이 저장됐다. 묶음 수는 세 방식의 기록이 있다는 뜻이며 모두 품질 통과했다는 뜻은 아니다.
- 첫 회차는 200형상 × FP16/FP32 × 세 방식 = 1,200측정으로 모두 기록됐다. 두 번째 회차는 6형상의 36측정만 있다. 세 번째 회차는 없고 세 회차를 완료한 조건도 없다.
- 첫 실행은 36건을 저장하고 `STOPPED`로 종료했다. KST 15:30:49에 정리했고, 재개한 실행은 37번째부터 1,200건을 추가해 17:20:33에 `ERROR`로 종료했다. task ID 중복·내부 누락·덮어쓰기 없이 계획의 첫 1,236건과 순서까지 일치한다.
- 첫 중단의 checked-runner exit 130, launcher 141/tee 130과 이후 품질 중단의 exit 1을 구분한다. 첫 실행의 신호 종료를 이번 클럭 위반 원인으로 단정하지 않는다.
- 재개한 실행의 마지막 120작업 구간(`segment_00009`)에서 문제가 검출됐다. worker는 `Clock/telemetry/data problem in this segment; stop before further collection`으로 다음 구간 전에 중단했다. 시간 REVIEW 하나만으로 즉시 멈춘 것이 아니라 구간 단위 센서 검사가 중단 사유다.
- 두 실행 모두 코어 `-rgc`와 메모리 `-rmc` 해제 명령이 exit 0으로 성공했다. 특정 현재 유휴 클럭이나 GPU의 현재 상태를 원격 확인한 것은 아니다.

## 문제 조건

1171~1173번째 측정인 `(M,N,K)=(2329,3998,66)` FP32의 세 방식 모두 순간 전력 제한과 목표 코어 클럭 불일치가 관측됐으며, 상대 IQR·첫/마지막 블록 드리프트도 각각 5% 기준을 넘었다.

| 방식 | 상대 IQR | 절대 드리프트 | cap 또는 클럭 이상이 겹친 시간 블록 |
|---|---:|---:|---:|
| allocate | 6.0% | 7.1% | 7/7 |
| prealloc | 5.6% | 7.2% | 7/7 |
| Graph | 6.9% | 12% | 2/7 |

98,575개 센서 표본 중 65개가 735 MHz이고, 순간 software power cap 활성은 149개다. 이상 표본의 처음~마지막 시각은 KST 17:16:17.335~17:16:28.286이다. 이 약 11초 범위를 연속 제한 지속시간으로 환산하지 않는다. 메모리는 모든 표본에서 6801 MHz, 설정 전력 한도는 70 W였다. 기록된 전력 범위는 약 21~71 W, 온도는 38~66°C이며 thermal slowdown 활성 표본은 없다. 50 ms 요청 표본은 연속·실효 커널 클럭의 증거가 아니다. 관측된 15 MHz 저하만으로 최대 12% 시간 변동 전체를 설명했다고 주장하지 않는다.

이상은 다음 FP16 allocate의 초기 안정화 4블록에도 겹친다. 해당 FP16 측정의 본 시간 블록 7개는 기준을 통과했으므로 측정별 PASS로 남아 있다. 준비 과정까지 이상이 전혀 없었다는 의미로 해석하지 않는다. 구간 전체 검사에서는 이 근거도 보존된다.

이전 780 MHz 문제 형상 `(3128,680,488)`은 이번 750 MHz 첫 회차의 두 정밀도·세 방식 6측정 모두 시간·관측 클럭 기준을 통과했다. 새 문제 형상은 앞선 세 형상 재진단 목록에 없었다. 작은 진단의 통과 범위를 전체 형상으로 확대할 수 없음을 보여준다.

## 정확성·반복성의 범위

저장된 1,236건은 설정된 수치 정확성 검사를 통과했다. 전체 출력 비교 12건과 표본 비교 1,224건을 구분한다. PASS 1,233건만의 최대 상대 IQR은 0.37%, 절대 드리프트는 0.87%다. 이 부분 통과 수치를 전체 3,600측정의 안정성으로 쓰지 않는다.

두 회차가 있는 것은 36개 형상·정밀도·방식 조합뿐이며 이들 범위/중앙값의 최대는 1.2%다. 전체 200형상의 세 회차 재현성은 미확인이다. 누적 카운터 해석 미해결은 542/8,652블록에 별도로 남아 있으며 제한 시간 비율로 환산하지 않는다.
