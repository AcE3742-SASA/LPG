## REVIEW 유지 사유

누적 SW Power Cap 카운터는 순간 비활성 표본 중에도 증가했으며 측정 블록 23/420개에 카운터 해석 이상 표식이 남는다. 이 수를 실제 제한 발생 횟수나 제한 시간 비율로 해석하지 않는다. 누적 카운터 문제는 UNRESOLVED로 보존한다. 따라서 원본 전체 gate=REVIEW·launcher exit 2는 유지하며 수집 실패와 구분한다. 관측 표본이 연속 클럭·유효 커널 주파수를 보장하지 않고 블록 평균이 단일 호출 스파이크의 부재를 보장하지 않는다.

원본 summary의 HOLD_PENDING_CHECK_REVIEW 문구는 자동 생성 당시의 검토 대기 상태다. 원본을 고치지 않고 이 문서와 admission_verified.json에 후속 검토를 기록했다. 기존 check_admission 함수를 로컬 복사본에 적용해 소스·프로토콜·환경·두 worker·시간/클럭·해제·검토 메모 요건을 통과했다. Ubuntu에서는 full 실행 시 이 검사를 다시 수행한다.
