원본 ZIP SHA-256은 `e8d2423393a69903eb21552b177689acef38eff02f846662fe7c906fae39ff05`다. ZIP 119,295항목의 CRC·경로·내장 소스 10파일과 의존 100파일을 검산했다. 변경하지 않은 분석기로 946구간을 다시 계산한 summary 전체와 비교한 17산출물이 반환본과 바이트 단위로 같다. 저장된 정확성 검사는 113,382건 모두 통과했다. 원본 해시·복구 이력은 [archive_validation.json](archive_validation.json), [provenance_validation.json](provenance_validation.json), 전체 검산은 [verification.json](verification.json)에 남겼다.

새 세션은 2026-09-30 23:25:25 KST에 FINISHED로 끝났다. 새 측정 1,800건의 세션 소요 시간은 약 1시간 59분이다. 새 15구간 모두 SW power-cap이 관측됐고 그중 9구간에는 코어 클럭 이탈도 있다. 메모리 클럭 이탈은 없다. 코어는 675~720 MHz, 메모리는 6801 MHz, 전력 한도는 70 W, GPU 온도는 39~69 C였다. 열 제한 활성 표본은 없다. 새 센서 표본은 136,507개이며 최대 기록 간격은 약 0.072초다.

결합 자료의 상대 IQR 최대 2.10%, drift 절댓값 최대 2.18%, 세 회차 상대 범위 최대 4.97%이며 회차 간 추가 플래그는 0건이다. 남은 REVIEW 중 일반 자료는 1,543건, fresh holdout은 257건이다. 잠금 시험의 시간값은 공개하지 않았다.

## 1,800건 전체가 REVIEW인 이유

기존 분석기는 한 120측정 구간에서 한 번이라도 전력 제한·클럭 이탈을 관측하면 그 구간 전체를 REVIEW로 표시한다. 별도로 각 측정의 시간 블록 안에서 직접 관측한 이상도 기록한다.

| 이번 1,800건의 구분 | 측정 수 |
|---|---:|
| 시간 블록 안에서 SW power-cap 직접 관측 | 48 |
| 위 48건 중 코어 클럭 이탈도 직접 관측 | 25 |
| 직접 플래그 없이 구간 전체 규칙으로 REVIEW | 1,752 |

직접 플래그가 없는 1,752건도 현행 기준상 REVIEW다. 관측되지 않았다는 이유로 PASS로 바꾸지 않았다. 약 50 ms 간격의 표본은 연속 관측이 아니므로 순간 이탈이 전혀 없었다고 단정할 수도 없다.

SW power-cap은 설정 전력 한도를 넘지 않도록 클럭이 조정됐음을 뜻한다([NVIDIA NVML 문서](https://docs.nvidia.com/deploy/nvml-api/latest/api/group__nvmlClocksEventReasons.html)). 이번 판단은 직접 활성 플래그와 관측 클럭에 근거한다. 누적 제한 카운터 해석 문제는 여전히 별개로 남아 있으며 활성 표본 수나 누적 카운터를 실제 제한 시간 비율로 환산하지 않았다.

## 다음 측정 제안과 준비 상태

같은 순서와 120건 구간을 그대로 반복하면 소수의 반복 이상이 다른 측정까지 다시 REVIEW로 묶을 가능성이 크다. 먼저 **문제가 직접 관측된 6개 FP32 형상의 남은 51개 task와 나머지 1,749개 task를 별도 수집 구간으로 분리**하는 것이 적절하다. 51건에는 이번에 직접 플래그가 없는 같은 형상의 3건도 포함한다. 기존 PASS 111,582건은 그대로 보존한다.

분리 목록은 [next_groups_PROPOSED.json](next_groups_PROPOSED.json)에 준비했다. 현재 REVIEW 목록과 합집합이 정확히 같고 중복이 없으며, 선택에는 시간값을 사용하지 않았다. 이는 **실행본이 아닌 제안 목록**이다. 새 런처·GPU 실행은 아직 없다. 후속 실행본에서는 720/6801 MHz·70 W, 정확성·시간 검사, task ID·입력 seed·split·Graph 설정을 유지하면서 수집 구간 분리와 실행 순서 변경을 manifest에 명시해야 한다. 구간 분리가 PASS를 보장하지는 않는다.

분리 뒤에도 같은 조건의 전력 제한이 반복되면 해당 조건을 고정 720 MHz 데이터셋의 미충족 사례로 남길지, 별도 조건 실험을 할지 결정해야 한다. 전력 한도나 클럭을 바꾼 자료를 기존 720 MHz/70 W 자료에 그대로 합치지 않는다. 이번 검토에서 기준 완화·자료 제외 확정·GPU 설정 변경은 하지 않았다.
