## REVIEW와 exit 2의 의미

분석기는 누적 카운터 해석 미해결을 남기기 위해 수집이 완료돼도 전체 gate를 REVIEW로 유지하도록 작성돼 있다. 이번에도 336블록 중 28블록에서 카운터 이상 표식이 남았다. 순간 전력 제한 활성 표본은 없지만 누적 SW Power Cap 카운터는 증가했다. 이를 제한 시간 비율로 환산하거나 드라이버 오류로 확정하지 않는다. 약 50 ms 간격의 센서 표본은 커널 구간 전체의 연속 클록 관측이 아니다.

전체 launcher의 exit 2는 이 REVIEW 판정에 따른 종료다. worker 오류나 미수집을 뜻하지 않는다. 저장된 `timing_and_sampled_clocks_pass`는 true이며 clock flags, 회차 간 초과와 재검토 측정 목록은 비어 있다.
