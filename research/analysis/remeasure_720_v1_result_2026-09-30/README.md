## 수집과 원자료 확인

실제 실행본은 v1이다. 내장 소스 9파일과 의존 100파일의 SHA-256이 로컬 보존본과 일치한다. 영어 출력 개정본 v2의 실행을 뜻하지 않는다. 새 worker는 2026-09-30 20:17:14 KST에 FINISHED로 종료했으며 새 기록 5,160건, worker 소요 시간 약 5시간 37분이다. worker 종료 코드는 0, 최종 launcher 종료 코드는 2(REVIEW), 출력 저장용 tee 종료 코드는 0이다. 코어와 메모리 클럭 해제 명령은 수락됐다.

14:29의 앞선 launcher는 종료 코드 1만 남아 있고 source 확인 이후의 상세 실패 로그는 없다. 원인을 추정해 채우지 않는다. 이후 14:36 launcher에서 정상적으로 수집을 마쳤으며 원시 기록의 중복은 없다.

원본 ZIP을 이 폴더에 복사하고 SHA-256, 119,279개 항목의 경로와 CRC를 확인했다. 압축 해제 크기는 6,794,174,168바이트다. 최초 전수 ZIP은 반환 자료의 `recovery/source_run.zip`에도 원래 SHA-256 그대로 남아 있다. 가져온 정상 108,222건의 내용, 원래 seq와 근거 파일 해시, task ID, seed, split 및 Graph 선택 12,144개가 보존됐다. 새 기록의 task ID 집합은 승인한 재측정 목록 5,160개와 정확히 같다.

기존 분석기로 946개 구간과 8,402,402개 센서 표본을 다시 읽었다. 재계산 summary 전체가 반환본과 같고 비교한 JSON, CSV, 보고서 17파일이 바이트 단위로 일치한다. SQLite quick_check는 ok이며 누락과 중복 task ID는 0건이다. 저장된 정확성 검사는 113,382건 모두 통과했다. 이 중 전체 출력 대조는 144건이고 나머지 113,238건은 표본 대조다.

## 남은 REVIEW

새 43구간 중 28구간의 3,360건이 PASS이고 15구간의 1,800건은 REVIEW다. 기존 정상 903구간의 108,222건은 모두 PASS를 유지했다.

- 순간 SW power-cap 관측: 14구간. 이 중 4구간에는 코어 클럭 이탈도 있다.
- 메모리 클럭 이탈: 별도 1구간.
- 일반 자료: 1,543건. 잠금 시험 자료(fresh holdout): 257건.

기존 규칙에 따라 문제가 관측된 구간의 120측정 전체를 REVIEW로 표시한다. 1,800건 각각에서 직접 클럭 이탈이 관측됐다는 뜻은 아니다. 남은 목록에는 292형상이 포함되며 FP16/FP32 각각 900측정, allocate/prealloc/Graph 각각 600측정이다. 형상 수와 측정 수를 구분한다. 잠금 시험 자료의 시간값과 성능 비교는 공개하지 않았다.

새 세션의 센서 385,185개에서 코어 클럭은 690~720 MHz, 메모리는 6800~6801 MHz였다. 전력 한도는 70 W, 관측 전력은 20.87~69.76 W, 온도는 38~67 C, 최대 기록 간격은 약 0.075초였다. 열 제한 활성 표본은 0개다. 관측 전력의 최대값이 70 W보다 낮다는 사실만으로 별도로 기록된 SW power-cap 활성 표식을 무효로 판단하지 않는다.

기존 자료와 새 자료를 합친 상대 IQR 최대는 0.86%, 첫 블록과 마지막 블록의 drift 절댓값 최대는 1.79%, 세 회차 상대 범위 최대는 4.97%로 각각 기존 5% 기준 이내다. 회차 간 추가 플래그는 0건이다. 이 지표는 시간 안정성 검사를 통과했다는 뜻이며 클럭 품질 REVIEW를 해제하는 근거는 아니다. 누적 제한 카운터 이상 표식은 전체 65,970블록, 새 측정 2,959블록에 남는다. 카운터 해석은 미해결 상태를 유지하며 전력 제한 시간 비율로 환산하지 않는다.

## 후속 처리

첫 재측정의 수집과 검토는 완료했다. 최종 데이터셋을 구성할 때 남은 REVIEW 1,800건을 제외하고 기존 split과 잠금 시험 구분을 유지한다. PASS 111,582건에는 시험과 대조 및 경계 측정도 들어 있으므로 이 수를 학습 표본 수로 쓰지 않는다. 추가 재측정을 결정하기 전에는 같은 조건에서 반복된 전력 제한과 클럭 이탈 구간을 점검할 필요가 있다. 기존 v1 명령을 같은 완료 폴더에서 다시 실행하면 이미 저장된 작업을 건너뛴다. 영어 출력 v2 역시 최초 5,160건용 준비본이므로 남은 1,800건을 자동으로 이어받는 실행본은 아니다. 이번 검토에서는 새 GPU 실행, 클럭이나 전력 설정 변경, 모델 학습을 하지 않았다.
