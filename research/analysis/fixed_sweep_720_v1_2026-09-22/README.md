# 720 MHz 전수 실행본 배포 검산

사용자가 2026-09-22 풀 스윕 진행을 요청했다. 완료한 720 MHz 200형상 측정기와 기존 전수 작업 목록을 재사용해 `fixed_sweep_720_v1`을 준비했다. 실제 GPU 전수 실행은 아직 시작하지 않았다.

- 코어 720 MHz, 메모리 6801 MHz, 기존 전력 한도 70 W.
- 총 113,382측정, 793,674블록. 주 측정 108,036개, 대조 3,942개, 경계 1,350개, 연산 기준 54개.
- 주 측정은 6,002형상 × FP16/FP32 × allocate/prealloc/Graph × 세 회차. 옛 10,000조건의 세 방식·세 회차 재측정 90,000개를 포함한다.
- 기존 full의 task ID·입력 seed·순서·split과 fresh holdout 1,000형상을 보존했다. 예비 200형상의 결과를 전수 폴더로 가져오지 않는다.
- 측정 worker, worker 제어, 중단 정리, 압축, 재개 검사와 Graph 선택 등 핵심 함수 8개의 AST가 기존 720 MHz 실행본과 같다. 분석기는 바이트 단위로 동일하다.
- 실제 완료 200형상 ZIP의 SHA-256·CRC·manifest·result digest·3,600 PASS·환경·클럭·품질·해제 상태를 진입 근거로 확인한다. 잘못된 근거는 GPU 명령 전에 거부한다.
- 로컬 16검사와 ZIP 추출본 16검사 PASS. 전체 작업 수·중복·옛 조건 포함·재개·엄격한 클럭 검사·실패 정리·저장·분석·런처 종료 코드·20초 진행률을 검증했다. GPU 명령은 테스트 대역으로 검사했다.
- 배포 ZIP CRC와 파일 8개의 바이트 일치, 기존 의존 83파일과 완료 결과 원자료 3,936파일의 해시 보존을 확인했다.
- 기존 tmux에서 실행하고 새 세션·창을 만들지 않는다. 기본 결과·로그·ZIP은 `/home/eu/gemm-research/scripts/fixed_sweep_720_v1/runs/` 내부다.
- 약 5~6일은 720 MHz 예비 수집 속도의 외삽이다. 새 형상에서 품질 검사를 계속 적용하고 누적 카운터 해석 미해결을 유지한다.
