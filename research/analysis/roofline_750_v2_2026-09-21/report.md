# 750 MHz 통합 Roofline v1 사전 검사 실패와 v2 수정

`roofline_750_v8_grkso.tar.gz`를 검토했다. 디렉터리 이름의 `v8_grkso`는 임의 생성 문자열이며, 포함된 실행 코드는 배포한 v1과 바이트가 같다.

- 전체 실행 종료코드는 1이다. 계획 306회 중 실제 측정은 0회이며, 클록 고정 명령에 도달하기 전에 중단했다.
- 실패 원인은 `BabelStream source tree is modified`다. 실제 Git 상태는 `?? build-cuda-sm89/`뿐이다. 이는 기존 미추적 빌드 디렉터리이며 추적된 소스의 수정 표시가 아니다.
- 사전 검사가 전체 Git 상태의 비어 있지 않음을 소스 변경으로 취급한 것이 원인이다. 바이너리 설치나 GPU 측정 자체가 실패한 결과로 해석하지 않는다.
- BabelStream 커밋은 예상한 `17ab377b0e919e14fd3df2b67268761fdac8abb3`이며 전력 한도 70 W·여유 VRAM 20089 MiB를 확인했다. 이번 실행은 바이너리 해시 검사 이전에 멈췄으므로 새 해시 검증 완료를 주장하지 않는다.
- 압축 SHA-256은 `6ad9d533af9ffaf3ce49733e3fb69df53d1da2328cedd4bab59a9f287ca70e44`다. 원본 29파일·압축을 `raw_v1_failure/`에 보존했고 내장 manifest의 28개 파일 해시는 모두 일치한다.

v2는 두 저장소 모두 전체 Git 상태를 기록하고, `git status --porcelain --untracked-files=no`로 추적 파일 변경만 차단한다. 소스 커밋 및 두 실행 바이너리 해시 검사는 유지한다. 기존 설치·빌드 폴더에는 손대지 않는다.

실제 실패한 Git 상태 출력을 재사용하는 회귀 검사에서 미추적 빌드 폴더를 허용하고 본측정을 시작하는지 확인했다. 추적 파일 수정과 스테이징은 설정 전에 차단한다. 17개 로컬 대역 실행, 5회 집계·예열 제외·변동 REVIEW·미완료 천장 거부를 확인했다. 기존 306개 계획과 각 도구 명령은 버전 표기 외에 그대로다. 실제 GPU 실행은 하지 않았다.

실행 파일은 `roofline_750_v2/`, 배포본은 `roofline_750_full_2026-09-21_v2.tar.gz`다. 기존 750/6801 MHz·70 W, 세 행렬 크기·16커널·본측정 5회 및 BabelStream 세 크기·5회를 유지한다. 다른 GPU 측정이 끝나고 정리된 뒤 사용자가 기존 tmux에서 새 패키지를 실행한다.
