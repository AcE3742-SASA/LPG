# 고정 조건 파일럿 패키지 검증

사용자의 “이상하네.. 해보자” 승인에 따라 fixed_pilot_v1을 준비했다. GPU 실행은 아직 하지 않았다.

- 새 회귀 검사 8개, 재사용 steps 10개·v6 10개·audit 10개를 통과했다. Python AST와 Bash 문법도 통과했다.
- 기존 의존 소스 35파일을 변경하지 않았다. 새 패키지는 기존 worker·Timer·GEMM·입력·정확성·telemetry·권한 갱신·복원 코드를 재사용한다.
- 실제 v6 파일럿 ZIP과 JSONL 해시, 192작업의 ID·순서·입력 seed·정확성 범위·Graph 묶음을 대조했다.
- 합성 전체 수집 192측정·1344블록·96쌍에서 기본 PASS, 시간/관측 클럭 PASS와 누적 카운터 REVIEW의 분리, 원래 5% 기준과 full HOLD를 검사했다.
- 클럭/메모리/전력 한도 불일치·제한 활성·N/A·내부 표본 누락·round 차이가 숨겨지지 않는지 검사했다. 분모·seed·묶음·정확성·누락/중복·소스·환경·worker 실패도 거부한다.
- 설정 실패·worker 실패·KeyboardInterrupt·분석 실패·부분 해제 실패와 진입 실패를 합성 명령으로 검사했다. 실제 Bash 프로세스 그룹 SIGINT에서 종료 정리 표식이 생성된 뒤 ZIP에 포함되는 것도 확인했다.
- ZIP 7파일 CRC와 원본 바이트를 대조했다. 세부 해시와 검사 결과는 validation.json, 실행 기록은 *tests.log에 있다.

실제 GPU 안정성·수치 결과·클럭 유지·카운터 해석·독립 세션 재현성을 확인한 것은 아니다. 새 GPU 실행은 사용자가 결과 ZIP을 반환한 뒤 검토한다. 예상 실행 15~25분은 계획용이며 worker 제한 시간은 40분이다.
